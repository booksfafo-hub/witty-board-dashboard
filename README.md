# Witty Board Dashboard

An original, static GitHub Pages dashboard for board-level pipeline review.

## Design principles

- One forecast-confidence measure, with its components visible.
- Core forecast is separated from exploratory pipeline generation.
- Material timing risk has an explicit management action.
- Figures use an illustrative, internally consistent dataset until a governed CRM data feed is connected.

## Publish to GitHub Pages

1. Create or select a repository you own.
2. Push this repository to GitHub.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.

No build step is required.
